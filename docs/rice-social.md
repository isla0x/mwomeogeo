# 밥풀 콕 · 상대 사진 스티커

기존 카메라 메인을 유지합니다. 상대 사진의 작은 밥풀 메뉴에서 콕 찌르기 또는 스티커 붙이기를 선택합니다. 빈 상대 자리에서도 오늘 식사 콕을 보낼 수 있습니다. 콕은 선택한 멤버에게만 발송하며 서버의 중복/쿨다운 제어를 사용합니다.

스티커는 사진마다 멤버당 하나입니다. 다섯 종류 중 골라 위치와 크기를 조절하고 붙이기를 누릅니다. 없음으로 내 스티커만 지울 수 있습니다. 원본 사진과 글은 수정하지 않습니다. 피드와 크게 보기에서 같은 오버레이와 붙인 사람을 표시합니다. 알림은 기존 좋아요/반응 수신 설정을 따릅니다. 최초 부착 시 알리고 위치 수정은 알리지 않습니다. 밥풀 키우기는 포함하지 않습니다.

## 적용 순서

1. `firebase deploy --only firestore:rules --project mwomeogeo`
2. `cd server/nudges && npm ci && npm run deploy`
3. 프로젝트 루트에서 `flutter pub get` 및 앱 빌드.

두 서버 변경을 먼저 배포해야 새 앱의 스티커와 상대 지정 콕이 동작합니다. 서버 배포나 실기기 푸시 전송은 이 코드 작업에서 수행하지 않았습니다. Android 푸시 지원 범위는 기존 구현과 같습니다(iOS APNs).

## 확인

Flutter 정적 분석, 앱 테스트, 알림 Worker 테스트를 실행합니다. 추가 Firestore 보안 테스트는 `tool/rules`의 에뮬레이터 테스트에 포함되어 있으며 Java와 Firebase 에뮬레이터 설치가 필요합니다.

검증 결과: Flutter 테스트 38개, Worker 테스트 14개 통과. lib/test 정적 분석 문제 없음. Firestore 에뮬레이터 테스트는 Java 런타임이 없어 실행하지 못했습니다. 실제 서버 배포와 iOS 아카이브는 별도입니다.
