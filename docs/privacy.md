# 뭐먹어? 개인정보 처리방침

시행일: 2026년 10월 22일

뭐먹어? 개발팀(isla0x)은 가까운 사람들과 식사 사진과 안부를 나누는 기능에 필요한 정보만 처리합니다.

## 처리하는 정보와 목적

- 사용자가 정한 표시 이름과 Firebase 익명 사용자 식별값: 기기에서 사용을 이어 가고, 식탁 참여와 작성자 권한을 확인하기 위해 사용합니다. 이메일이나 비밀번호를 입력하는 회원가입 화면은 없습니다. 익명 식별값은 실명 인증을 의미하지 않지만 같은 앱 사용자의 기록과 연결됩니다.
- 식탁 이름, 참여자 식별값, 초대 코드, 식사 사진, 한마디, 댓글, 반응, 작성 시각: 기록 보관과 초대받은 식탁 참여자 사이의 공유에 사용합니다. 초대 코드를 아는 다른 사람이 식탁에 참여할 수 있으므로 공개하지 마세요.
- 알림을 허용한 기기의 푸시 토큰과 알림 설정: 같은 식탁의 다른 참여자가 보낸 식사 안부 알림을 전달하기 위해 사용합니다. 마지막 토큰 갱신 시각과 중복 알림을 제한하는 요청 기록도 처리합니다.

광고, 광고 식별자, 앱 간 추적, 위치 수집을 사용하지 않습니다. 사용자 정보를 판매하거나 광고 목적으로 제공하지 않습니다.

## 기기 권한

카메라는 사용자가 직접 촬영할 때, 사진 선택은 사용자가 사진을 고를 때 사용합니다. 사진첩 전체를 서버로 전송하지 않습니다. 알림은 사용자가 수신을 켜고 운영체제 권한을 허용한 경우에 사용합니다. iPhone 설정에서 권한을 변경할 수 있습니다.

## 저장과 공유

기기에만 저장한 기록은 앱 전용 공간에 보관합니다. 공유 식탁의 기록과 익명 인증에는 Google Firebase Authentication 및 Cloud Firestore를 사용합니다. 공유 사진은 압축해서 저장하며 해당 식탁의 참여자만 접근하도록 권한을 확인합니다. Firebase 기본 데이터베이스 위치는 서울입니다.

식사 알림 서버는 Cloudflare Workers와 Durable Objects를 사용하고, 실제 iPhone 알림 전달에는 Apple Push Notification service를 사용합니다. 이들 서비스 제공자는 서비스 운영을 위해 정보를 처리하며 해외 인프라에서 처리될 수 있습니다. 푸시 토큰은 다른 식탁 참여자에게 공개하지 않습니다. 알림 서버에는 사진이나 댓글 본문을 보내지 않습니다.

서비스 제공자의 개인정보 안내: [Google](https://policies.google.com/privacy), [Firebase](https://firebase.google.com/support/privacy), [Cloudflare](https://www.cloudflare.com/privacypolicy/), [Apple](https://www.apple.com/legal/privacy/).

## 보관과 삭제

공유 게시물과 사진은 작성자가 앱에서 삭제할 때 서버에서도 삭제하며, 해당 게시물의 댓글과 반응을 함께 정리합니다. 삭제 중 연결이 끊긴 경우 앱에서 다시 삭제할 수 있습니다. 앱을 삭제하는 것만으로 공유 서버의 기록이 삭제되지는 않습니다. 기기에만 저장된 기록은 앱 데이터 삭제와 함께 사라질 수 있습니다.

식사 알림 받기를 끄면 알림 서버에 등록된 해당 사용자의 기기 토큰을 삭제합니다. 30일 이상 갱신되지 않은 토큰에는 알림을 보내지 않습니다. 앱 삭제 자체를 서버가 즉시 알 수는 없으며, Apple이 토큰 만료를 알려 준 경우 해당 토큰을 정리합니다. 중복 방지 요청 기록은 24시간 뒤 정리합니다. 익명 인증 정보나 남은 공유 데이터의 삭제 문의는 아래 지원 창구를 이용할 수 있습니다.

앱 데이터 초기화나 재설치 후에는 익명 식별값이 달라져 기존 작성자 권한을 복원하지 못할 수 있습니다. 함께 공유하는 사람은 화면을 캡처하거나 내용을 따로 보관할 수 있습니다.

## 문의와 변경

[뭐먹어? 지원](https://github.com/isla0x/mwomeogeo/blob/feature/meal-nudges/docs/support.md)에서 오류 및 개인정보 처리 관련 문의 방법을 안내합니다. 공개 문의에는 사진, 초대 코드, 전화번호 등 개인정보를 올리지 마세요. 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신합니다.
