# 뭐먹어? 화면 개편

버전: 1.1.0 (15)

## 바뀐 화면

- 우유빛 바탕, 살구색·버터색과 코코아색 선으로 화면과 팝업을 통일했습니다.
- 카메라·달력·밥그릇·알림·반응 아이콘과 밥알 캐릭터를 Canvas로 직접 그렸습니다.
- 메인에서 바로 촬영하고 사진첩 사진도 선택할 수 있습니다. 촬영 뒤에는 기존 등록 화면에서 날짜·끼니·문구를 확인하고 올립니다.
- 상단 올리기 버튼을 고정하고 하단을 식탁·달력·설정으로 정리했습니다.
- 공통 상단은 가운데 제목을 빼고 식탁 선택과 올리기 버튼만 표시합니다.
- 사람별 좌우 자리를 유지한 사진 피드와 달력 날짜별 사진 보기, 과거 날짜 기록 추가를 함께 포함합니다.
- 설정에 사진·댓글·좋아요·밥 안부 알림의 개별 스위치와 식탁 관리를 배치했습니다.
- 글자와 아이콘의 시각적 크기를 줄이면서 주요 버튼의 터치 영역은 유지했습니다. 큰 글씨와 좁은 화면에서는 사진을 한 열로 표시합니다.

폰트는 승인된 나눔스퀘어라운드 Regular/Bold를 적용했습니다. 글자 크기는 유지했고, 지원되지 않는 문자는 Pretendard로 보완합니다. 원본 글꼴의 라이선스는 `assets/fonts/LICENSE_NanumSquareRound.txt`에 포함합니다.

밥풀 둘을 대표 캐릭터로 사용합니다. 앱 아이콘, 식탁 탭, 촬영 버튼, 프로필, 빈 화면, 등록 완료 화면은 같은 Canvas 그림을 사용합니다. iOS와 Android 앱 아이콘도 갱신했습니다. iOS 촬영 위젯은 밥풀과 작은 카메라만 담고 기존 촬영 링크를 유지합니다. 위젯 그림은 앱과 같은 원본을 PNG로 내보내 사용합니다.

밥풀은 재해석한 도형을 제거하고 승인된 원본 `design/rice-widget-reference.jpeg`의 윤곽·눈 위치·색을 추출한 경로로 복원했습니다. `tool/trace_rice_reference.py`가 공유 경로를 생성합니다. 원본은 변경하지 않습니다. 숫자 03은 생성된 시안 이미지에 그려진 글자이며 앱의 글꼴 파일에 해당하지 않습니다.

아이콘을 다시 내보내려면 `CI=true flutter test --no-pub tool/render_brand_assets_test.dart`를 실행한 뒤 Pillow가 설치된 Python으로 `python3 tool/pack_brand_assets.py`를 실행합니다. iOS 마케팅 아이콘은 투명도 없는 RGB PNG로 패키징합니다.

## 설치 전 준비

날짜별 기록 기능의 Firestore 규칙 변경도 포함되어 있습니다. 새 앱은 오늘과 지난 날짜 사진 모두 `recordedAt`을 전송하므로, 공유 식탁 업로드를 사용하기 전에 이 소스의 `firestore.rules`를 먼저 배포해야 합니다. 기존 기록을 지우거나 옮기는 작업은 필요하지 않습니다.

```sh
npx --yes firebase-tools@15.34.0 deploy --only firestore:rules --project mwomeogeo
flutter pub get
flutter build ipa --build-name=1.1.0 --build-number=15
open build/ios/archive/Runner.xcarchive
```

위 명령은 Mac의 프로젝트 폴더에서 실행합니다. Firebase 로그인이 필요하면 `npx --yes firebase-tools@15.34.0 login`을 먼저 실행합니다. iOS 카메라 플러그인 의존성은 Mac에서 CocoaPods로 설치됩니다. 앱과 위젯은 Flutter의 같은 버전·빌드 번호를 사용합니다.

Android는 카메라 플러그인의 요구 사항에 따라 Android 7.0(API 24) 이상입니다. 카메라 접근을 거부해도 사진첩에서 사진을 고를 수 있습니다. 음성은 녹음하지 않고 촬영 사진은 시스템 사진첩에 자동 저장하지 않습니다. 앱의 자체 보관 파일은 별도로 존재합니다.

## 확인한 범위

- Flutter 테스트 36개 통과: 기존 기록·좌우 자리·날짜별 추가·작은 화면·큰 글씨와 카메라 촬영 콜백, 앞뒤 전환, 화면 이동/백그라운드 시 해제 및 재개, 권한 거부 시 대체 경로.
- 전체 프로젝트 정적 분석 이상 없음. 설치된 node_modules는 앱 소스 분석에서 제외합니다.
- Dart 포맷과 git diff 공백 검사 통과.

카메라는 플랫폼 인터페이스 대역으로 검사했습니다. 실제 아이폰 카메라, iOS 서명·아카이브, 설치, App Store 업로드 및 운영 Firestore 규칙 배포는 이 환경에서 수행하지 않았습니다.

원본 밥풀 복원 후에는 원본 윤곽과의 비교, iOS 아이콘 크기/RGB 검사 및 패치 적용을 확인했습니다. 위 Flutter 테스트·정적 분석 결과는 이번 그림 복원 전 적용본의 결과입니다. 현재 환경에는 Flutter SDK가 없어 그림 복원 후 Flutter 검사를 재실행하지 않았습니다.
